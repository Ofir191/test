# משמר

מערכת לניהול קריאות ביטחון וסיורים: מוקד, סייר, משתמש מורשה ומנהל מערכת.

פתיחת קריאה על בית מזהה את האזור, משבצת את הסייר הפעיל (כפתור פעיל, משמרת, ואזור או מיקום), שולחת התראה, ומאפשרת לסייר לסמן התקבלה, בדרך, הגעתי וסגירה. קריאות פתוחות בטווח של 500 מטר (ניתן לשינוי) מוצעות כפוליגון.

## הרצה

```bash
npm install
npm run dev
```

ואז לפתוח [http://localhost:3000](http://localhost:3000).

## מה כלול

- מוקד: מפה, פתיחת קריאה, מעקב סטטוס, שיוך ידני, קישור קריאות לפוליגון, היסטוריה
- סייר: סימון פעיל/לא פעיל, מיקום, התראות, ניווט ב-Google Maps וב-Waze, עדכון סטטוס
- משתמש מורשה: פתיחת קריאה על הבתים שלו ומעקב סטטוס
- ניהול: משתמשים, אזורים, בתים, ייבוא אקסל, משמרות, רדיוס פוליגון וטווח GPS
- דוחות לפי תאריך, אזור, סייר וסטטוס, כולל ייצוא CSV

הממשק בעברית וכיוון ימין-לשמאל. השעות מוצגות לפי שעון ישראל.

## פריסה ב-Vercel

הפרויקט מוגדר ל-Node 22, כי מסד הנתונים משתמש ב-`node:sqlite`. ב-Vercel אין דיסק קבוע, ולכן המסד נשמר ב-`/tmp` של כל שרת: נתוני ההדגמה נטענים מחדש כשהשרת מתחיל, ושינויים לא משותפים בין עותקים שונים. לשימוש אמיתי צריך מסד חיצוני ומשתנה `SESSION_SECRET`.
